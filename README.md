Aplicação web Full Stack desenvolvida para conectar famílias que procuram babás a profissionais que buscam oportunidades de trabalho.

O projeto possui cadastro e autenticação de usuários, diferentes perfis de acesso, criação e visualização de oportunidades e sistema de candidaturas.

Desenvolvido para praticar desenvolvimento Full Stack, APIs, autenticação, banco de dados e integração entre Front-end e Back-end.
